# 🚀 Portfólio — Paulo Henrique Moreira

Portfólio profissional desenvolvido para apresentar minha trajetória, experiência, serviços, projetos, tecnologias e formas de contato.

O projeto foi construído com foco em **Front-End**, **responsividade**, **acessibilidade**, **performance**, **UX/UI** e organização de código, utilizando uma identidade visual dark com destaques em laranja e elementos inspirados em tecnologia.

---

## 👨‍💻 Sobre o Projeto

Este portfólio foi desenvolvido utilizando **React.js**, **Tailwind CSS** e **Framer Motion**, com uma arquitetura baseada em componentes reutilizáveis e dados centralizados.

A aplicação apresenta:

- Perfil profissional
- Serviços
- Projetos reais
- Tecnologias e ferramentas
- Tecnologias em aprofundamento
- Redes sociais
- Formulário de contato
- Download de currículo

O design segue uma estética **dark, moderna e tecnológica**, utilizando tons de preto e grafite, destaques em laranja, elementos gráficos, glow, animações e microinterações.

# 🧩 Arquitetura em Componentes

O projeto foi dividido em componentes com responsabilidades específicas, facilitando manutenção, leitura e evolução.

### `BackgroundDecor.jsx`

Responsável pelos elementos gráficos e detalhes tecnológicos exibidos no background.

### `Header.jsx`

Responsável pelo cabeçalho, navegação principal, menu mobile e atalhos para as seções.

### `Hero.jsx`

Apresenta nome, cargo profissional, imagem principal, redes sociais e chamadas para ação.

### `About.jsx`

Apresenta informações profissionais e os principais diferenciais do desenvolvedor.

### `Services.jsx`

Exibe os principais serviços e formas de contribuição profissional.

### `Projects.jsx`

Responsável pelo carrossel manual de projetos, navegação, animações, imagens, informações, badges e links externos.

### `TechStack.jsx`

Exibe as tecnologias e ferramentas utilizadas e as tecnologias atualmente em processo de aprofundamento.

Os ícones são carregados diretamente de arquivos SVG armazenados em `src/assets/icons`.

### `Contact.jsx`

Apresenta formulário de contato funcional e canais de comunicação.

### `Footer.jsx`

Finaliza a página com informações complementares e navegação.

### `SectionHeading.jsx`

Padroniza títulos, subtítulos e destaques das diferentes seções.

# 💼 Carrossel de Projetos

O carrossel foi desenvolvido diretamente em React, sem dependência de uma biblioteca específica de slider.

A navegação é realizada manualmente.

## Primeiro plano

Apresenta o projeto atualmente selecionado com:

- Imagem em destaque
- Título
- Descrição
- Tecnologias
- Link para o projeto

## Segundo plano

Apresenta parcialmente:

- Projeto anterior
- Próximo projeto

Esses elementos possuem escala e blur diferentes do projeto principal.

## Planos adicionais

Projetos mais distantes recebem:

- Maior desfoque
- Menor escala
- Menor opacidade

Isso cria uma sensação de profundidade semelhante a um carrossel tridimensional.

# 🎬 Animações

O portfólio utiliza **Framer Motion** para criar transições e animações.

Entre elas:

- Digitação automática do nome
- Fade-in
- Entrada lateral
- Movimento vertical
- Scale
- Blur
- Animações de carrossel
- Microelevação
- Hover
- Glow
- Transições de estado

As animações respeitam:

```css
prefers-reduced-motion
```

permitindo reduzir movimentos quando essa preferência está configurada no sistema operacional do usuário.

# 📧 Formulário de Contato

O formulário possui os campos:

```text
Nome
E-mail
Assunto
Mensagem
```

O envio é realizado utilizando integração com **FormSubmit via AJAX**.

Durante o processo de envio, o formulário apresenta feedback ao usuário:

```text
Enviando...
```

e informa se a mensagem foi enviada com sucesso ou se ocorreu algum problema.

O formulário também utiliza um campo invisível do tipo **honeypot** como proteção básica contra bots.

# ▶️ Como Executar o Projeto

## 1. Clone o repositório

```bash
git clone https://github.com/paulohenriquemoreira/portfolio_paulo_henrique_moreira.git
```

## 2. Acesse o diretório

```bash
cd portfolio_paulo_henrique_moreira
```

## 3. Instale as dependências

```bash
npm install
```

## 4. Inicie o ambiente de desenvolvimento

```bash
npm run dev
```

## 5. Abra o endereço exibido pelo Vite

Normalmente:

```text
http://localhost:5173
```
